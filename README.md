# 智能任务管理系统

技术栈：Node.js（Express 后端）+ React（前端）+ Supabase（PostgreSQL 数据库）+ GitHub（代码托管）+ Vercel（部署）

## 功能

- 输入任务标题 + 选择优先级（高 / 中 / 低），点击"添加"入库
- 任务列表按创建时间倒序显示（最新在最上面）
- 每条任务显示标题、优先级标签、完成状态
- 每条任务支持"完成 / 未完成"切换、删除
- 已完成任务文字自动加删除线、颜色变淡
- 顶部按优先级筛选：全部 / 高 / 中 / 低
- 数据持久化在 Supabase 云端数据库，关闭浏览器再打开数据仍在

## 本地运行

1. 安装依赖：

```bash
npm install
```

2. 复制环境变量模板并填入自己的 Supabase 凭据：

```bash
cp .env.example .env
```

填写：

```
SUPABASE_URL=https://你的项目ID.supabase.co
SUPABASE_ANON_KEY=sb_publishable_你的key
```

3. 启动：

```bash
npm start
```

访问 http://localhost:3000

## 数据库表结构（Supabase 中执行）

```sql
create table if not exists tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  priority text not null default '中' check (priority in ('高', '中', '低')),
  completed boolean not null default false,
  created_at timestamptz not null default now()
);

alter table tasks enable row level security;

create policy "Allow anon read" on tasks for select using (true);
create policy "Allow anon insert" on tasks for insert with check (true);
create policy "Allow anon update" on tasks for update using (true) with check (true);
create policy "Allow anon delete" on tasks for delete using (true);
```

## 接口一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/tasks?priority=高 | 查询列表（可按优先级筛选，倒序） |
| POST | /api/tasks | 添加任务 `{ title, priority }` |
| PATCH | /api/tasks/:id/toggle | 切换完成状态 |
| DELETE | /api/tasks/:id | 删除任务 |
| GET | /api/health | 健康检查 |

## 部署（Vercel）

导入 GitHub 仓库后，在 Environment Variables 中配置：

| Name | Value |
| --- | --- |
| SUPABASE_URL | https://你的项目ID.supabase.co |
| SUPABASE_ANON_KEY | sb_publishable_你的key |
| NODE_ENV | production |
| CLIENT_BASE_PATH | / |

> 注意：`.env` 已在 `.gitignore` 中，切勿把密钥提交到 GitHub。
